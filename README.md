# مصنع الريلز الذكي

مشروع جديد مستقل لإنتاج فيديوهات قصيرة أصلية، ومراجعتها، وجدولتها، ونشرها على صفحة Facebook، ثم قياس نتائجها. الهدف تقليل العمل اليدوي مع الإبقاء على مراجعة بشرية قبل النشر.

## الحالة الحالية

هذه نسخة إثبات مفهوم أولية. ينتج GitHub Actions مسودة عربية وصوتًا عصبيًا عربيًا، ثم يبني فيديو رأسيًا بخمس لوحات علمية متتابعة وحركة مرئية وترجمة. لا يوجد اتصال بصفحة Facebook ولا نشر محتوى.

ابدأ بقراءة [سجل الحالة](PROJECT_STATUS.md) و[تقييم الجدوى](docs/FEASIBILITY.md). لا تضع أسرارًا أو رموز وصول في هذا المستودع.

## قرارات معروفة

- الميزانية الحالية: صفر.
- الاستخدام: الكمبيوتر والهاتف، مع أولوية الواجهة الملائمة للهاتف.
- المنصة الأولى: صفحة Facebook عامة مرتبطة بحساب المستخدم.
- المجال المرشح والمعتمد مبدئيًا في المحادثة السابقة: غرائب وحقائق علمية موثقة، بالعربية الفصحى المبسطة ولجمهور عربي عام.
- التشغيل المفضل: مهام سحابية عبر GitHub Actions، مع نموذج مفتوح المصدر إذا أمكن ضمن الحدود المجانية.

## القاعدة التشغيلية

المهام المجدولة على GitHub Actions تنفذ على عمال مؤقتين وليست خادمًا دائمًا، وقد تتأخر. لا يُعتمد موعد نشر أو نجاح نشر إلا بعد تأكيد المنصة. راجع القيود والقرارات في سجل المشروع قبل التنفيذ.

## أول تجربة تقنية

يوجد Workflow يدوي أولي لتوليد مسودة فقط عبر Ollama وQwen2.5 1.5B. يتطلب عنوان فكرة وملاحظات/روابط مصادر، ويحفظ الناتج كـ artifact لمدة 7 أيام. تحقق التشغيل السحابي بنجاح، وتستغرق التجربة نحو دقيقتين على CPU. اختبارات منطق المولّد المحلية ناجحة (3/3).

## تجربة إنتاج الفيديو

يأخذ Workflow الفكرة والمصادر ويولد المسودة بنموذج محلي، ويستخدم Piper لصوت عربي عصبي، ثم ينشئ خمس لوحات علمية مختلفة مع حركة جسيمات وانتقال كاميرا وترجمة عربية. يُصدّر الفيديو رأسيًا 9:16 عبر FFmpeg. نختبر حاليًا حدًا أقصر للنص (80–100 كلمة) بعد أن تجاوزت إحدى المسودات مدة الدقيقة. نجاح البناء لا يكفي للحكم على جودة الصوت أو ملاءمة الرسوم؛ راجع [آخر تشغيل](https://github.com/ashraf18275/majnoun-reels-factory/actions/runs/38353095876) للاستماع والمراجعة. لا يوجد نشر على Facebook.
